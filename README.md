# Ultimate Warriors 2

Secuela de [Ultimate Warriors](https://github.com/elJulioDev/Ultimate-Warriors), un juego de pelea 2D de Dragon Ball construido originalmente en PowerPoint con VBA.

Ahora reescrito desde cero en **Godot 4.7** con GDScript, conservando la esencia del original: combate arcade con transformaciones, ki, combos, escenarios dinámicos y soporte para dos jugadores.

## Objetivo

Llevar el juego a un motor de juego real, mejorando la jugabilidad, los gráficos y la experiencia, manteniendo el espíritu del primer juego hecho en PowerPoint.
